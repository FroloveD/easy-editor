# Easy Editor — элементный визуальный конструктор (вариант 2)

Визуальный редактор сайтов в духе [Webstudio](https://webstudio.is): страница — это **свободное дерево элементов**, каждый элемент редактируется и стилизуется индивидуально. Второй проект, дополняющий блоковый [easy-block-editor](https://github.com/FroloveD/easy-block-editor) («вариант 1», в духе Tilda).

## Запуск

Никакой сборки и зависимостей — просто откройте `index.html` в браузере или:

```bash
npx serve .
```

## Возможности (MVP)

- **Дерево элементов**: контейнер, секция, шапка, футер, меню, заголовок, текст, ссылка, кнопка, картинка, список, пункт списка — любая вложенность.
- **Канвас WYSIWYG**: клик выделяет элемент, двойной клик редактирует текст прямо на странице.
- **Навигатор**: дерево структуры с синхронизацией выделения; хлебные крошки над панелью стилей.
- **Панель стилей**: display (flex/grid), направление/выравнивание/промежуток flex, ширина/высота, padding/margin, шрифт (размер, насыщенность, выравнивание, цвет), фон, скругление, прозрачность. Поля принимают любые CSS-значения.
- **Контент**: текст, href для ссылок, src/alt для картинок.
- **Действия**: выше/ниже, дублировать, удалить, сбросить стиль.
- **Drag-and-drop**: перетаскивание элементов в навигаторе и по канвасу с «призраком» и маркером вставки — рядом с элементом или внутрь контейнера, с учётом направления flex; перетаскивание отключено во время инлайн-редактирования и в режиме просмотра.
- **Undo/redo** (Ctrl+Z / Ctrl+Shift+Z), Delete удаляет выделенный элемент.
- **Экспорт HTML**: самодостаточный `index.html` со всеми стилями (Ctrl+E).
- **Автосохранение** в localStorage, RU/EN интерфейс.
- **Интерфейс в духе Webstudio**: вкладки «Элементы / Навигатор» в левой панели, переключатель брейкпоинтов (десктоп / планшет / мобильный) в тулбаре, сегментированные контролы для display и типографики, бейдж с именем тега у выделенного элемента, hover-подсветка элементов канваса.

## Архитектура

```
js/i18n.js     — словарь RU/EN, t(key), переключатель языка
js/elements.js — EL_DEFS (типы элементов), STYLE_PROPS (панель стилей), стартовый шаблон
js/editor.js   — дерево { id, def, tag, text, attrs, style, children },
                 рендер канваса из дерева, генерация CSS (.e-{id}{...}),
                 навигатор, инспектор, undo/redo, экспорт
js/dnd.js      — drag-and-drop: «призрак», маркер вставки, перенос узлов дерева
js/ui.js       — вкладки панелей, брейкпоинты, сегментированные контролы, бейдж выделения
```

Ключевой принцип WYSIWYG: канвас и экспорт строятся из одного дерева одной функцией —
CSS-правила `.e-{id}{...}` генерируются один раз и используются и в редакторе, и в экспорте.
